# QuickReplyTool Releases

本仓库仅用于托管「客服效率工具 / QuickReplyTool」的官方二进制安装包、便携包、增量补丁与软件内 OTA 更新清单（不含源代码）。

This repository hosts official binary releases, portable packages, incremental patches, and in-app OTA manifests for QuickReplyTool only (no source code is stored here).

- 请前往 [Releases](https://github.com/wangyuhui570-rgb/QuickReplyTool-Releases/releases) 下载最新版本安装包或绿色便携版。
- 切勿手动删除名为 `update-manifest` 的发布条目，桌面客户端会自动通过其中的 `latest.json` 检查更新。
